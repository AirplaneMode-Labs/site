# Security policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| none released yet | - |

The site is deployed from `main` to GitHub Pages; there are no versioned releases.

## Reporting a vulnerability

Email jtushar53@gmail.com with a description and, where possible, a reproduction. You will
get an acknowledgement within seven days.

Airplane Mode Labs follows a 90-day coordinated disclosure window: we aim to fix and publish
within 90 days of the report and coordinate the publication date with you.

## Test key material

Any Ed25519 key material that appears in an Airplane Mode Labs repository is the published,
non-secret RFC 8032 section 7.1 test vector. It is public test data and signs nothing real.
This repository contains no key material.

## Telemetry

The site collects no telemetry, sets no cookies, runs no scripts and loads nothing from a
third party, so there is nothing to opt out of.
