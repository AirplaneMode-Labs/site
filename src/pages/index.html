Offline-first AI, built from the papers up

Airplane Mode Labs builds the tools that AI usually needs the cloud for, so that they run offline, in the browser, on small hardware. The first product is an offline document intelligence kit for Indian financial, legal and healthcare documents that works on an 8 GB laptop with the Wi-Fi off.

What is here

  • Papers: the reading list, with each paper's claim, our status and notes.
  • Benchmarks: measurements on modest hardware, or an honest "not measured".
  • Write-ups: what a paper claimed, what held up, what did not.

How we work

Papers before tools
We read the key papers for a component before we look at how others built it. Existing tools are something to measure against, not something to copy.
Small repositories with one job each
Each tool gets its own repository, a clear purpose and a README with a benchmark we are willing to defend.
The browser and small hardware are the default
WebAssembly, WebGPU, OPFS and IndexedDB first. Anything that needs a server has to justify itself.
Measure, and publish what did not work
A shared harness reports memory, latency, size and quality on modest machines. Negative results are published alongside positive ones.
Ship something small every week
A small public artefact every Saturday beats a large private one at the end of the quarter.
Write it down
Every reimplemented paper gets a short note: the claim, what held up, what did not.
