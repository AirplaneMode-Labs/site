Start here

Airplane Mode Labs builds offline-first AI tools that run in the browser. If you have two minutes, do the first section; if you have ten, do the second. Everything below says what it does not do yet, and nothing here is published to a package registry: the quick starts build from a clone of the repository.

1. Try a demo in your browser

Each demo runs in the browser tab: nothing is uploaded, and the only requests are for the page's own files. Each has a box titled "What this demo does not do yet". Start with the first one; it needs no download.

  • glyphsift: drop in Devanagari text and see whether it is clean or damaged. No model, no download.
  • pagetriage: open a PDF and see what is on each page before anything reads it. No model, no download.
  • localdata: store and search vectors in the browser, flat scan or an optional graph. No model, no download.
  • runtime: the capability profile, the signed-manifest checks and the tamper lab. No model, no download.
  • site: this site, as a demo of itself: papers, benchmarks and write-ups, with no script on any page.
  • dockit, the offline PDF question-answering app, is the one with a download. Before you open it: it keeps {{dockit-size}} on your device once its models have downloaded (a small language model and a search model; you do this once, online), and works offline from then on. It reads text-layer PDFs only. Open it on a good connection, then switch Wi-Fi off: open dockit.

2. Try the libraries in two minutes

Each library repository has a "Try it in two minutes" section that needs no model download and no test key. It builds the library from a clone (so it needs the toolchain named there, and the package registries once for that first build), installs what it built into an empty folder and runs it with no network. Its code blocks are run by a test in the repository's CI, so the section cannot drift from the code. Nothing is published to npm, PyPI or crates.io yet, which is why each one builds from the clone.

  • runtime: sign a manifest with a key made for the run, verify it, change one number and watch the verifier refuse it.
  • localdata: store five synthetic vectors, build a graph index over them and ask for the three nearest.
  • pagetriage: run the built npm package, Python wheel and command-line binary on one synthetic PDF.
  • glyphsift: score a clean and a noisy line of Devanagari from the command line, Python and Node.

3. The numbers, and what they do not say

The benchmarks page lists every figure with the command that produced it. Every figure comes from a developer machine, and the 8 GB laptop column reads not measured on 8 GB in every row: whether the tools fit an 8 GB Windows laptop with the Wi-Fi off has not been measured yet.

Each repository states what does not work yet in its Limitations section:

  • dockit
  • runtime
  • localdata
  • pagetriage
  • glyphsift

Package names use the placeholder scope @airplanemode until the registry handles are reserved. There is no tag and no release yet.
